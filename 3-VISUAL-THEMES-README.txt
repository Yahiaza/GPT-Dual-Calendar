GPT Dual Calendar — 3 Visual Themes + Organized Settings
=================================================================

هذا الباتش للنسخة المستقرة، وليس نسخة Orbit التجريبية.

الجديد:
1) إعادة تنظيم الإعدادات إلى 4 تبويبات:
   - المظهر
   - التقويم
   - التذكيرات
   - النظام والبيانات

2) إخفاء زحمة الألوان:
   - التحكم الأساسي ظاهر بشكل مختصر.
   - الألوان اليدوية داخل "الألوان المتقدمة" القابلة للفتح/الإغلاق.

3) ثلاثة أشكال UI كاملة:
   CLASSIC
   - الواجهة المتوازنة المعتادة.

   ORBIT
   - Header عائم.
   - Sidebar عائم وأضيق.
   - Reminder Panel عائم.
   - Calendar cards كبيرة الحواف.
   - أسماء الأيام Pills.
   - خلايا الأيام Tiles منفصلة.
   - ظلال ومسافات حديثة.

   LEDGER
   - واجهة أعمال كثيفة.
   - Header داكن.
   - حواف شبه مربعة.
   - شبكة تقويم دقيقة.
   - شريط أيام داكن.
   - Sidebar أوسع وتنظيم جدولي.

4) كل شكل له Light + Dark Palette مقترحة.
5) يمكن بعد اختيار الشكل تعديل اللون يدويًا.
6) يحتفظ زر الخروج النهائي أسفل الإعدادات.
7) يحتفظ تنسيق التاريخ العلوي الجديد:
   12 / أغسطس (08) / 2026 - 29 / صفر (02) / 1448 هـ

طريقة التركيب:
- فك ZIP داخل مجلد المشروع.
- Replace للملفات.
- npm run dev
- الإعدادات > المظهر > شكل التطبيق.
