GPT Dual Calendar 1.0.9 — Gregorian Calendar Border Fix
===========================================================

المشكلة:
إطار كارت التقويم الميلادي كان مربوطًا بمتغير:
--calendar-grid-line

وده متغير خطوط شبكة الأيام الداخلية، وليس لون حدود الثيم العامة.

التصحيح:
تم ربط الإطار الخارجي للتقويم الميلادي بـ:
--border

وبذلك تغيير "لون الحدود" من إعدادات الثيم يطبق على:
- كارت التقويم الميلادي
- كارت التقويم الهجري
- باقي عناصر الواجهة التي تستخدم حدود الثيم

لم يتم تغيير:
- Grid الداخلي
- الألوان الأخرى
- ترتيب التقويم
- رقم الإصدار
- أي منطق خاص بالتذكيرات أو التواريخ

للتجربة:
npm run dev
