GPT Dual Calendar — Full Color Customization Patch
==================================================

انسخ الملفات داخل المشروع بنفس المسارات.

أهم الإضافات:
- قسم جديد في الإعدادات: "ألوان الواجهة".
- تخصيص مستقل للوضع الفاتح والوضع الداكن.
- جميع التعديلات تظهر Live فور تغيير اللون.
- حفظ الألوان تلقائيًا في localStorage مع إعدادات التطبيق.
- النسخة الاحتياطية تشمل الألوان أيضًا.
- Preset جاهز: "كحلي احترافي".
- استعادة ألوان الوضع الحالي أو جميع الألوان.

الألوان القابلة للتعديل:
1. خلفية التطبيق.
2. الخلفيات الثانوية والكروت.
3. الشريط العلوي.
4. القائمة الجانبية.
5. لوحة التذكيرات.
6. الحدود والـ Hover.
7. النص الرئيسي والثانوي والخافت.
8. Accent الرئيسي والقوي والخفيف.
9. خلفية كروت التقويم وخطوط الشبكة.
10. أرقام الأيام.
11. أسماء أيام الأسبوع.
12. اسم الشهر والسنة.
13. النص أسفل اسم الشهر.
14. خلفية وخط اليوم المحدد.
15. دائرة وخط اليوم الحالي.
16. خلفية وحد وخط مربع التاريخ العلوي.
17. خلفية ولون الساعة.
18. لون جرس التذكير.
19. لون "تم بعض التذكيرات".
20. لون "تم جميع التذكيرات".
21. اللون الهجري في شاشة تحويل التاريخ.
22. ألوان الحذف والخطر.

بعد الاستبدال:
npm run dev

لا تحتاج Build لاختبار الألوان.
