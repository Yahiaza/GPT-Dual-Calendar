GPT Dual Calendar 1.0.10 — Midnight Date Rollover Fix
=======================================================

المشكلة:
إذا ظل التطبيق مفتوحًا بعد الساعة 12 منتصف الليل، كان "اليوم الحالي"
يبقى بتاريخ اليوم السابق لأن Calendar كان يحسب getToday() مرة واحدة فقط
عند فتح التطبيق.

التصحيح:
- اليوم الفعلي أصبح يتحدث تلقائيًا مع تاريخ Windows.
- إذا كان المستخدم واقفًا على اليوم الحالي، عند دخول يوم جديد:
  * ينتقل التحديد لليوم الجديد.
  * يتحدث الـHeader.
  * يتزامن التقويم الميلادي.
  * يتزامن التقويم الهجري.
  * يتحدث اليوم المحدد في لوحة التذكيرات.
- إذا كان المستخدم يتصفح تاريخًا آخر يدويًا، لن يتم سحبه تلقائيًا.
- عند رجوع الجهاز من Sleep أو عودة التركيز للبرنامج يتم فحص التاريخ فورًا.
- لم يتم تغيير رقم الإصدار: ما زال 1.0.10.
- عندما تعمل npm run build عندك، نظامك الحالي يستطيع رفعه إلى 1.0.11.

الملف المعدل:
src/components/calendar/Calendar.jsx

للتجربة:
npm run dev
