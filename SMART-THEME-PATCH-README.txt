GPT Dual Calendar — Smart Theme + Typography Patch
==================================================

التعديلات:
- أسماء أيام الأسبوع Extra Bold داخل شريط Rounded بحواف وحدود.
- كلمة "الوقت الحالي" Extra Bold.
- "التقويم الميلادي" و"التقويم الهجري" تحت اسم الشهر أكبر وأعرض.
- مولّد ثيم ذكي داخل الإعدادات:
  1) اختر لونًا أساسيًا.
  2) اضغط "طبّق التناسق".
  3) التطبيق ينشئ Light + Dark تلقائيًا.
  4) اكتب اسمًا واضغط "حفظ الثيم".
  5) الثيمات المحفوظة تظهر أسفل المولد ويمكن تطبيقها أو حذفها.
- التحكم اليدوي الكامل يظل موجودًا.
- أضيف تحكم بخلفية وحدود شريط أسماء أيام الأسبوع.
- الثيمات المحفوظة تدخل ضمن نفس settings وتدخل تلقائيًا في النسخة الاحتياطية.

بعد الاستبدال:
npm run dev
