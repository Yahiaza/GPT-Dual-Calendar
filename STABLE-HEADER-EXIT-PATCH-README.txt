GPT Dual Calendar — Stable Header + Exit Patch
================================================

هذا الباتش للنسخة المستقرة قبل Orbit:
GPT-Dual-Calendar-Latest-Full-Project-With-Updates

التعديلات:
1) التاريخ العلوي أصبح:
   الأربعاء | 12 / أغسطس (08) / 2026 - 29 / صفر (02) / 1448 هـ

2) الأرقام تتبع إعداد 123 / ١٢٣ الموجود داخل البرنامج.

3) إضافة زر "خروج" أسفل زر "الإعدادات" في القائمة الجانبية.

4) زر "خروج" يغلق التطبيق نهائيًا:
   - يغلق النافذة.
   - يوقف التطبيق.
   - يزيل أيقونة Tray.
   - تتوقف التنبيهات لأن البرنامج لم يعد يعمل في الخلفية.

5) زر X العلوي لم يتغير، ويظل يعمل حسب إعداد سلوك الإغلاق الحالي.

طريقة التركيب:
- فك الملف المضغوط داخل مجلد المشروع.
- اختر Replace للملفات الموجودة.
- شغّل:
  npm run dev
